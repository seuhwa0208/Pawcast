# PAWCAST 상품 검색 조건 백엔드 전달안

## 1. 검색 대상 관

| 화면 | API 값 권장 | 설명 |
| --- | --- | --- |
| 강아지관 | `DOG` | 강아지용 사료·간식·영양제 |
| 고양이관 | `CAT` | 고양이용 사료·간식·영양제 |
| 식기·급수관 | `DEVICE` | 공용 급식기·급수기·식기·필터 |

DB에는 화면 이름 대신 `targetType` 또는 `petType` 코드로 저장하는 것을 권장한다. 식기·급수 상품은 `DEVICE` 또는 `ALL` 중 하나로 팀에서 통일한다.

## 2. 관별 분류

### 강아지관·고양이관 공통

| 대분류 | 중분류 |
| --- | --- |
| 사료 | 건식 사료, 습식 / 화식, 기능성 사료, 연령별 사료 |
| 간식 | 덴탈 간식, 동결건조 / 트릿, 육포 / 저키, 츄르 / 파우치 |
| 영양제 | 관절 / 뼈, 피부 / 모질, 장 / 유산균, 눈 / 종합영양 |

### 식기·급수관

| 대분류 | 중분류 |
| --- | --- |
| 급식기 | 자동 급식기, 수동 급식기, 휴대용 급식기 |

| 일반 식기 | 도자기 식기, 스테인리스 식기, 높이 조절 식기 |
| 정수 / 필터 | 정수 필터, 교체용 필터, 세척 용품 |

## 3. 브랜드 목록

브랜드는 문자열 직접 비교보다 `brandId`로 검색하고, 화면에는 브랜드명을 내려주는 방식을 권장한다.

### 강아지관

`내추럴발란스`, `로얄캐닌`, `아카나`, `오리젠`, `웰니스`, `인스팅트`, `퓨리나 프로플랜`, `하림펫푸드`, `힐스`, `ANF`

### 고양이관

`내추럴발란스`, `뉴트리플랜`, `로얄캐닌`, `아카나`, `오리젠`, `웰니스`, `이나바`, `퓨리나 원`, `힐스`, `ANF`

### 식기·급수관

`딩동펫`, `리스펫`, `바비온`, `샤오미`, `캣잇`, `펫세이프`, `하겐`, `호머런펫`, `PETKIT`, `PETLIBRO`

## 4. 원료·소재 조건

### 식품관 원료

- 육류: 닭고기, 오리, 소고기, 양고기, 칠면조, 돼지고기
- 수산물: 연어, 참치, 흰살생선, 조개류
- 부원료: 고구마, 감자
- 기능성 성분: 유산균, 글루코사민, 오메가

`조개류`는 상품 원료 데이터에서 조개·가리비·홍합·굴 등을 묶는 상위 코드로 관리하는 것을 권장한다.

### 식기·급수관 소재·필터 성분

식기·급수 상품에는 식품 원료 대신 `materialIds` 또는 `featureIds`를 사용한다.

- 활성탄
- 스테인리스
- 도자기
- 실리콘

현재 프론트는 임시로 상품명에 포함된 단어를 검사하지만, 백엔드는 반드시 상품-원료 및 상품-소재 연결 테이블을 기준으로 검색해야 한다.

## 5. 공통 검색 조건

| 조건 | 권장 파라미터 | 자료형 | 현재 화면 값·규칙 |
| --- | --- | --- | --- |
| 검색어 | `keyword` | String | 상품명 부분 검색 |
| 관 | `targetType` | Enum | `DOG`, `CAT`, `DEVICE` |
| 대분류 | `categoryId` | Long | 단일 선택 |
| 중분류 | `subcategoryId` | Long | 단일 선택 |
| 브랜드 | `brandIds` | Long[] | 다중 선택, 항목 간 OR |
| 원료 | `ingredientIds` | Long[] | 다중 선택, 항목 간 OR |
| 소재·특징 | `materialIds` | Long[] | 식기·급수관 다중 선택 |
| 최저 가격 | `minPrice` | Integer | 원 단위, 옵션 최저 판매가 기준 권장 |
| 최고 가격 | `maxPrice` | Integer | 원 단위, 마지막 구간은 생략 가능 |
| 최저 평점 | `minRating` | Decimal | `1`, `2`, `3`, `4`, `4.5` |
| 재고 있음 | `inStock` | Boolean | `true`이면 판매 가능 재고 1개 이상 |
| 정렬 | `sort` | Enum | 아래 정렬 코드 참고 |
| 페이지 | `page` | Integer | 0부터 시작 권장 |
| 페이지 크기 | `size` | Integer | 기본 20, 최대 100 권장 |

### 현재 가격 구간

| 화면 표시 | API 변환 |
| --- | --- |
| 1만원 이하 | `minPrice=0&maxPrice=10000` |
| 1~3만원 | `minPrice=10000&maxPrice=30000` |
| 3~5만원 | `minPrice=30000&maxPrice=50000` |
| 5만원 이상 | `minPrice=50000` |

경계 가격이 중복되지 않게 백엔드는 `price >= minPrice AND price < maxPrice` 규칙을 사용한다. 단, 화면 문구를 정확히 “이하”로 유지하려면 첫 구간만 `<= 10000`으로 별도 정의해야 하므로 팀 합의가 필요하다.

### 현재 평점 구간

- 1점대: `1.0 <= rating < 2.0`
- 2점대: `2.0 <= rating < 3.0`
- 3점대: `3.0 <= rating < 4.0`
- 4점대: `4.0 <= rating < 4.5`
- 4.5점 이상: `4.5 <= rating <= 5.0`

### 정렬 코드

| 화면 표시 | 권장 값 |
| --- | --- |
| 인기순 | `POPULAR` |
| 신상품순 | `NEWEST` |
| 낮은 가격순 | `PRICE_ASC` |
| 높은 가격순 | `PRICE_DESC` |
| 할인율순 | `DISCOUNT_DESC` |
| 판매량순 | `SALES_DESC` |
| 리뷰 많은순 | `REVIEW_DESC` |
| 평점 높은순 | `RATING_DESC` |

## 7. 필터 선택지 API 권장

관과 카테고리에 따라 없는 브랜드·원료가 자동으로 빠지도록 선택지 전용 API를 두는 것이 좋다.

```http
GET /api/products/search-filters?targetType=DOG&categoryId=1
```

응답에는 해당 범위에서 실제 사용 가능한 `categories`, `subcategories`, `brands`, `ingredients` 또는 `materials`, 가격 최솟값·최댓값을 포함한다. 프론트가 브랜드와 원료 목록을 하드코딩하지 않아도 되며, 관리자 상품 등록 내용이 검색 화면에 자동 반영된다.

## 8. 검색 구현 시 주의사항

- 여러 브랜드 선택은 OR, 여러 원료 선택도 현재 프론트와 동일하게 OR로 처리한다.
- 서로 다른 조건 그룹은 AND로 결합한다. 예: 고양이 AND 참치·연어 중 하나 AND 1~3만원 AND 재고 있음.
- 가격은 대표가가 아니라 판매 가능한 옵션 중 최저 판매가 기준 검색을 권장한다.
- 평점은 승인된 리뷰 집계값을 기준으로 한다.
- 품절 판정은 상품 상태와 옵션 재고를 함께 확인한다.
- 검색어는 상품명·브랜드·원료까지 확장할 수 있지만, 초기 API는 현재 프론트와 동일하게 상품명 검색부터 적용해도 된다.
